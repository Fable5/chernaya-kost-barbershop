# Демонстрационные сайты барбершопа

В репозитории хранятся две самостоятельные версии сайта:

- `template/` — универсальный шаблон для персонализации под другой барбершоп.
- `chernaya-kost/` — версия, адаптированная под барбершоп «Чёрная Кость» по предоставленным фотографиям.

В каждой папке лежат отдельные `index.html`, `styles.css`, `script.js` и README. Чтобы посмотреть сайт, откройте соответствующий `index.html`.

Обе формы записи демонстрационные: данные сохраняются только в localStorage текущего браузера и не отправляются салону.
