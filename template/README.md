# Шаблонный сайт барбершопа

Универсальная демонстрационная версия сайта. Все данные для адаптации собраны в объекте `BARBERSHOP_CONFIG` в начале `script.js`: название, цвета, контакты, фотографии, услуги, мастера и расписание.

## Запуск

Откройте `index.html` в браузере. Изображения и веб-шрифты загружаются из интернета.

## Демо-запись

Форма проверяет данные и сохраняет записи в `localStorage` только в текущем браузере. Заявки не отправляются в салон. Выбор даты ограничен ближайшими тремя месяцами, а занятое время становится недоступным.

Перед использованием замените демонстрационные контакты, цены, мастеров, расписание, фотографии и отзывы на подтверждённые данные своего барбершопа.
